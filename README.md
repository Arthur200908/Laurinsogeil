# Laurinsogeil

Dies ist eine einfache Webseite mit einem Taschenrechner, der Zahlen multiplizieren kann — standardmäßig ist 10 mal 10 vorausgefüllt.

Dateien:
- `index.html`
- `style.css`
- `script.js`

So verwenden Sie die Webseite:
1. Öffnen Sie `index.html` im Browser.
2. Ändern Sie bei Bedarf die Zahlen.
3. Klicken Sie auf "Rechnen".
